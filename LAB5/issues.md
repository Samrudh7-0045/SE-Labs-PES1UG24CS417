# Static Code Analysis Issues Report

This document records the static code analysis findings detected by **Bandit**, **Flake8**, and **Pylint** on `course_enrollment_system.py` prior to remediation.

## Identified Issues Table

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| Shell Injection via `os.system` (Bandit B605 / B607) | Vulnerability (High) | 63 | Spawning a shell command using `os.system("echo ... " + filename)` allows command injection if `filename` contains unvalidated input or shell metacharacters. | Replace `os.system` process invocation with Python's native `print()` statement or `subprocess.run` with `shell=False`. |
| Weak Cryptographic Hash MD5 (Bandit B324) | Security (High) | 52 | `hashlib.md5` is cryptographically broken and vulnerable to collision and preimage attacks when used for security identifiers or student verification. | Replace MD5 with SHA-256 (`hashlib.sha256`) for secure student roll number hashing. |
| Insecure Code Execution via `eval` (Bandit B307 / Pylint W0123) | Vulnerability (Medium) | 47 | `eval(discount_expr)` executes arbitrary Python expressions at runtime, allowing remote code execution if expressions are supplied externally. | Safely evaluate arithmetic discounts using AST parsing (`ast.literal_eval` / parsed syntax tree validation) or accept numeric discount percentages directly. |
| Dangerous Mutable Default Argument (Pylint W0102) | Bug (High) | 15 | `audit_trail=[]` evaluates once at function definition time; the list persists across multiple calls, causing unexpected state sharing between enrollments. | Change default parameter to `audit_trail=None` and initialize `if audit_trail is None: audit_trail = []` inside the function body. |
| Predictable Pseudo-Random Number Generator (Bandit B311) | Security (Low) | 56 | `random.randint` uses the Mersenne Twister PRNG, which is completely predictable and insecure for OTP generation. | Use Python's cryptographically secure `secrets` module (`secrets.randbelow` or `secrets.SystemRandom().randint`). |
| Bare Exception Handler (Flake8 E722 / Pylint W0702 / Bandit B110) | Bug / Practice | 31 | `except:` without exception type catches all exceptions, including `KeyboardInterrupt` and `SystemExit`, silently hiding unintended crashes. | Catch specific expected exception types (`KeyError`) and log or handle gracefully instead of silent suppression. |
| Hardcoded Sensitive Token (Bandit B105) | Security (Low) | 75 | Hardcoded registrar token `'REGISTRAR_PORTAL_ROOT_SECRET_2026'` stored directly in source code risks credential leakage. | Retrieve the token dynamically from environment variables (`os.environ.get`) with a safe default. |
| Unhandled Resource Cleanup & Encoding (Pylint W1514, R1732) | Code Smell | 60 | `open(filename, "w")` without a context manager (`with`) can leak file descriptors if exceptions occur, and omits explicit character encoding. | Use a `with open(filename, "w", encoding="utf-8") as file:` context manager block. |
| Singleton Comparison with `==` (Flake8 E711 / Pylint C0121) | Style / Bug | 37 | Comparing `courses.get(course_id) == None` violates PEP 8 and can fail with custom `__eq__` implementations. | Replace comparison with `is None` or idiomatic key lookup `if course_id not in courses:`. |
| Unused Imports and Variables (Flake8 F401, F841 / Pylint W0611, W0612) | Code Smell | 4, 36, 46, 68 | `import math`, local variable `lab_fee`, `base_fee`, and loop variable `cid` are defined but never used, cluttering the namespace. | Remove unused import `math` and unreferenced local variables. |
| Non-conforming Function & Variable Naming (Pylint C0103) | Style | 12, 15, 27, 35, 45, 51, 55, 59, 66 | Function names (`enrollStudent`, `dropCourse`, etc.) use camelCase instead of PEP 8 `snake_case`, and `total_tuition` violates uppercase constant convention. | Refactor function names to `snake_case` and encapsulate global state or use proper naming conventions. |
| Missing Docstrings (Pylint C0114, C0116) | Documentation | 1, 15, 27, 35, 45, 51, 55, 59, 66, 74 | Module and functions lack docstrings describing purpose, arguments, and return values. | Add descriptive docstrings complying with PEP 257. |
| Line Length Violations (Flake8 E501 / Pylint C0301) | Style | 7, 8, 9, 15, 23, 79 | Multiple lines exceed PEP 8 line length limits (79 / 100 characters), e.g., line 23 is 135 characters. | Wrap long lines cleanly across multiple lines. |
| Missing Final Newline (Flake8 W292 / Pylint C0304) | Style | 87 | The file lacks a trailing newline character at the end of the file. | Ensure the file ends with a trailing newline. |
| Scope Shadowing (Pylint W0621) | Code Smell | 66 | Parameter `courses` shadows outer module-level dictionary `courses`. | Rename parameter to `catalog` or `course_catalog`. |
