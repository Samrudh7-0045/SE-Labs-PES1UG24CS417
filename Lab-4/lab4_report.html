Task 1: Bullet Collision Detection Fix

Bug: Bullets passed straight through enemies when shooting rapidly. The code was iterating over self.player_bullets while calling self.player_bullets.remove(bullet) inside the same loop. Modifying the list during iteration shifted index positions, skipping the next bullet.

Fix: Iterate over a shallow copy of the list using self.player_bullets[:] so removing items from the original list does not cause skipped bullets.

# Iterate over shallow copy to avoid skipping elements
for bullet in self.player_bullets[:]:
    for enemy in self.enemy_grid.alive_enemies():
        if bullet.rect().colliderect(enemy.rect()):
            enemy.alive = False
            self.player_bullets.remove(bullet)
            self.score += 1
            self.sound_manager.play_enemy_hit()
            break

Task 3: Replay Option with Difficulty Settings

Fix: Added 3 difficulty levels (Easy, Medium, Hard) that adjust enemy speed and fire rate. Added a difficulty badge on the HUD, and keys 1 (Easy), 2 (Medium), 3 (Hard) to restart on Game Over, or Q to exit.

DIFFICULTIES = {
    "Easy":   {"enemy_speed": 1.0, "fire_chance": 0.001, "color": (100, 220, 100)},
    "Medium": {"enemy_speed": 1.6, "fire_chance": 0.003, "color": (240, 200, 60)},
    "Hard":   {"enemy_speed": 2.5, "fire_chance": 0.007, "color": (255, 80, 80)},
}

def reset_game(self, difficulty=None):
    if difficulty and difficulty in self.DIFFICULTIES:
        self.current_difficulty = difficulty
    diff_cfg = self.DIFFICULTIES[self.current_difficulty]

    self.player = Player(self.width // 2 - 20, self.height - 50, 40, 20)
    self.enemy_grid = EnemyGrid(self.width, speed=diff_cfg["enemy_speed"])
    self.enemy_fire_chance = diff_cfg["fire_chance"]
    self.player_bullets.clear()
    self.enemy_bullets.clear()
    self.score = 0
    self.game_over = False

Task 4: Sound Effects

Fix: Used Python's wave and math modules to synthesize 8-bit retro arcade sound effects without requiring external sound files:

  • Player shoot: Laser frequency sweep (shoot.wav)
  • Enemy hit: Explosion noise (enemy_hit.wav)
  • Game over: Descending arpeggio sequence (game_over.wav)
class SoundManager:
    def __init__(self):
        self.shoot_sound = pygame.mixer.Sound("game/assets/sounds/shoot.wav")
        self.hit_sound = pygame.mixer.Sound("game/assets/sounds/enemy_hit.wav")
        self.game_over_sound = pygame.mixer.Sound("game/assets/sounds/game_over.wav")

    def play_shoot(self): self.shoot_sound.play()
    def play_enemy_hit(self): self.hit_sound.play()
    def play_game_over(self): self.game_over_sound.play()
